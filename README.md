# Живое Наследие — Telegram WebApp

Прототип Telegram WebApp для питомника хвойных растений «Живое Наследие».

## Файлы

- `index.html` — готовая к показу версия (все изображения встроены в файл, можно открыть напрямую или разместить через GitHub Pages).
- `app.html` — исходник для разработки (изображения подключаются отдельными файлами).
- `build-final.mjs` — Node-скрипт сборки: встраивает изображения в `app.html`, результат записывает как `app-final.html`.
- `*.jpg` — изображения товаров, используемые исходником `app.html`.

## Статус

Клиентский прототип (HTML/CSS/JS), без бэкенда. Интеграции с банком, Telegram Bot API и онлайн-кассой оформлены как явные точки подключения в коде — сейчас работают как заглушки.
